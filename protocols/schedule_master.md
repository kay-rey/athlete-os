# Schedule Master — Coach + Athlete Operating System

**Role:** Jiu-jitsu coach. Class grid lives in `protocols/coaching_calendar.md`. This file merges coaching duty with Phase 1 recomp lifting/nutrition.

**Chronotype:** Habitual wake ≈ **11:00 AM** on non-early-mat days. **Exceptions:** Wednesday if teaching 9:00am Toddler (wake ≈ **8:00 AM**); Saturday for 9:00am Adults (wake ≈ **7:30–8:00 AM**).

**Sleep bank:** ~2:00–3:00 AM lights-out when waking ~11:00; pull bedtime earlier (~11:30 PM–12:30 AM) before Wed/Sat early calls. Gate 7 Mg **60 min pre-bed** + allergy med at lights-out.

**Prescription meds:**
- **Sertraline 75 mg @ 3:00 PM daily** — psyllium ≥2 hrs away (lunch fiber ≈12:40 PM).
- **Allergy medication at bedtime.**

**Athlete hard days (default):** Friday Adults Comp + Saturday Adults. Not every evening adults class.

## 7 Daily Adherence Gates

### Gate 1 (Breakfast on wake)
45g protein + D3 (2,000–5,000 IU)/K2 (100–180 mcg) + half-dose Omega-3s. Clock ≈11:15 most days; ≈8:00 Wed early; ≈7:45 Sat early.

### Gate 2 (≈12:40 PM Pre-Lunch Fiber) — shift earlier on Sat
5g psyllium (2.5g Wk 1) in 12 oz + 6 oz chaser, 15–20 min pre-lunch. Never within 2 hrs of hard mat rounds. Never within ±2 hrs of 3:00 PM sertraline. **Saturday:** use post-mat ~12:15 slot instead of 12:40.

### Gate 3 (≈1:00 PM Lunch) — Sat may be post-mat plate
50g protein + 150g cooked black beans + veggies + **Kirkland Daily Multi**.

### Gate 3.5 (3:00 PM — Sertraline 75 mg)
Fixed. Water OK. No psyllium ±2 hrs.

### Gate 4 (4:30 PM Pre-Mat Anchor)
25g protein → ≥100g daytime protein by 5:00 PM (target 110–125g). Lands right before Lil Rollers/Kids start on teach nights. **Saturday:** hit protein at Gate 1 + post-mat shake instead (no 4:30 gate needed).

### Gate 5 (Hard Athlete Days — Fri Comp + Sat Adults; optional Thu)
1. **T−45m clamp:** 35–45g fast carbs + 500–750mg Na+ in 16 oz  
2. **T+15m:** 30g WPI + 5g creatine  
3. **T+45m:** 5g psyllium (2.5g Wk 1) — respect sertraline gap  
4. **T+65m:** Milpa dinner (50g protein + 175–200g black beans + veggies + 50g avocado + half Ω-3s)

Coach-mode evenings (most Mon–Thu): skip full clamp if not rolling hard; still use Gate 4 + Gate 6.

### Gate 6 (Teach-only / easier nights)
Psyllium 15–20 min pre-dinner after last class → Milpa dinner + Ω-3s (+ creatine if not used in Gate 5).

### Gate 7 (60 min pre-bed → bedtime)
Mg bisglycinate 200–300mg elemental + Mg L-threonate 144mg elemental → allergy med at lights-out.
