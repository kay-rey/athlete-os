# Chicken tortilla soup (no strips)

Phase-friendly Milpa pot. Taste → `nutrition/preferences.md`. Crock twin → `slow_cooker.md`. Chili → `turkey_chili.md`.

**No tortilla strips** (his call) — flavor from broth, beans, spices, lime. Optional **1 warm corn tortilla** on the side if carbs remain.

## Why this build
- **Chicken breast** (not thighs) · high protein  
- **Black beans** · fiber/carbs without CFA sodium bomb  
- **Low-sodium broth** + spices · you control salt  
- Skip cream, cheese packets, fried strips, ranch

## Pot (≈4–5 bowls)
| Ingredient | Amount |
|------------|--------|
| Boneless skinless **chicken breast** | **1.5–2 lb** |
| **Low-sodium** chicken broth | **6 cups** (≈1.4 L) |
| Diced tomatoes (no-salt-added if possible) | **1–2 cans** (14.5 oz) |
| Black beans, **rinsed** | **2 cans** (15 oz) |
| Onion, chopped | **1** |
| Garlic, minced | **3–4 cloves** |
| Frozen corn (optional) | **1 cup** |
| Chili powder | **1–1½ tbsp** |
| Cumin | **2 tsp** |
| Oregano | **1 tsp** |
| Salt / pepper / optional pinch MSG | To taste |
| Lime | **1–2**, juice at the end |
| Optional heat | Jalapeño or chipotle in adobo **1–2 tsp** (not a whole can) |

**Skip:** cream of chicken, heavy cream, cheese packet, tortilla strip bag, cilantro (wife).

## Cook
**Slow cooker:** dump all except lime → Low **6–7 h** or High **3–4 h** → shred chicken in pot → lime → taste salt.  
**Instant Pot:** 12–15 min high pressure → 10 min natural release → shred → lime.  
**Stovetop:** sauté onion/garlic → add rest → simmer covered **25–35 min** until chicken shreds → lime.

## Bowl (Gate dinner)
| Build | ≈ |
|-------|---|
| Soup with generous chicken + beans | **~45–55P** target |
| Optional **30–40 g avocado** | Fat if day is lean |
| Optional **1 corn tortilla** or measured FF cheese / Greek yogurt | Not required |
| **No strips** | Default |

Log a Lose It custom recipe after you weigh the finished pot (same tare method as chili if using the **832 g** pot).

## vs CFA tortilla soup
Homemade is **lower sodium**, same vibe, strips optional forever. CFA bowl was fine as a one-off; this is the weekly staple.
