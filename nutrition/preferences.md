# Food preferences (taste SoT)

Macros → `nutrition/phases.csv`. Gates → `day/schedule.md`. Recipes → `nutrition/recipes/`. This file owns **likes / dislikes** only.

**Hierarchy:** Likes tell the agent *what flavors you’ll stick with*. They do **not** set portion size. When taste pulls toward heavy starch / binge-prone builds, default advice is whatever is **healthiest for Phase recomp + anti-binge** (protein, Milpa, satiety) — still using foods he enjoys, just not maxed.

## Household cooking
- **Wife cooks all dinners.** Don’t prescribe elaborate self-cooked Gate 5/6 menus as the default.
- Your job: hit Gates **1–4** yourself (breakfast, lunch, pre-mat protein); at dinner **portion/track** what she made toward Phase macros.
- Share with her (simple ask, not a lecture): lean protein + beans/veg often; Mexican/American flavors; **no pickles / mustard**; easy pots = **chili (99/1 turkey)** or **albóndigas / tortilla / fideos / chicken noodle** (see soups).
- Log dinner in Lose It / tell the agent after — estimate plate if needed.

### Slow cooker / Instant Pot?
- **Does not make food healthier by itself** — ingredients + portions do (lean meat, beans, low-sodium broth, moderate starch). Cream soup bases / fatty cuts / junk noodles in a crockpot are still junk.
- **Can help adherence:** dump-and-go chili, tortilla soup, shredded chicken, beans → more homemade dinners, leftovers for lunch, less “empty kitchen → binge.”
- **Worth getting if** you don’t already batch in a regular pot and she wants set-it-and-forget-it for your staples. **Skip if** a Dutch oven / big pot already covers chili & soups — no need to buy for health points.
- **If buying one appliance:** a **multi-cooker (Instant Pot–style)** > slow-cooker-only — same pot for pressure (beans/chicken fast) + slow mode. ~6-qt is enough for 2 + leftovers. Costco/Sam’s often stock them.
- Healthy crock use: 99/1 turkey or chicken, rinsed beans, no-salt tomatoes, low-sodium broth; **add noodles late** (or cook separate) so they don’t turn to mush and get over-scooped.

## Soups — healthy to make? (yes — Phase defaults)

Homemade > restaurant/canned. All four fit taste. **Healthiest pattern:** lean protein + veg volume + **moderate** potato *or* noodle (not both piled), low-sodium broth. Taste likes heavy potato/noodle — **do not prescribe heavy as the default**.

### Shared Phase rules (tell wife / batch cook)
- Broth: **low-sodium** chicken broth + salt to taste (or no-salt tomatoes + cumin/chili/oregano/lime)
- Protein: **lean and generous** — chicken breast/thigh trimmed, **99/1 turkey** or **96/4** meatballs; drain fat. Target ~**45–60g protein** / bowl
- Veg: onion, garlic, carrot, celery, zucchini, tomato, cilantro — **this is the volume**, not extra pasta
- Starch: **potato preferred over noodle** when choosing one; Phase default = moderate (table); heavy = occasional, not nightly
- Finish: lime, cilantro, salsa; light avocado if fat allows; skip sour cream lakes / cheese dumps
- Costco/Sam’s: rotisserie (skin off), broth, frozen veg, potatoes, fideo/egg noodles, 99/1 turkey

### Starch defaults (Phase 1) — healthiest first
| In the bowl | Carbs (approx) | Agent default |
|-------------|----------------|---------------|
| **Potato** ~1 medium (~150–170g cooked) | ~**30–35g** | **Yes — Phase default** for albóndigas / chicken soups |
| **Noodles / fideo** ~1–1.5 oz dry | ~**20–30g** | **Phase default** for fideos / chicken noodle — enough to taste, not a pasta bowl |
| Potato **or** noodle at default | ~**30–40g** | Normal soup dinner |
| Heavy potato (2 med) **or** ~2–3 oz dry noodle | ~**55–70g** | Occasional OK if lunch was Milpa-light; not the ask every time |
| Potato **+** noodle both heavy | ~**70–100g+** | **Avoid as habit** — blows dinner carbs, weaker satiety vs beans/potato-only |

**Why not “a lot” every night:** binge risk + refined-noodle density leaves less room for protein/Milpa and weaker fullness per calorie than potato + beans + veg.

| Soup | Healthiest build | Notes |
|------|------------------|-------|
| **Albóndigas** | **Best potato soup** | 99/1 turkey meatballs; **1 medium potato**; zucchini/carrot volume |
| **Chicken tortilla** | **Best overall** (Milpa) | Chicken + tomatoes + **black beans** + chile/lime; few baked strips — skip noodle/potato pile |
| **Chicken noodle** | Good if moderated | Breast/thigh + veg + **1–1.5 oz dry** noodles — not a ramen refill |
| **Fideos** | Good if moderated | Toast fideo + tomato + **shredded chicken**; same noodle cap; don’t make it pasta soup |

**Phase target bowl:** ~**400–550 kcal · 45–60P · 30–45C · 8–15F**.  
**Restaurant:** saltier/oilier — OK sometimes; log it.

**Verdict:** Make these soups. Prefer **protein + veg + one moderate starch** (potato > noodle; beans when it fits). Enjoy potato/noodle flavors without making “heavy” the prescription.

| | Classic Fresca 12 fl oz can (Coca-Cola label) |
|--|-----------------------------------------------|
| Calories | **0** |
| Carb / sugar | ~0–1 g / **0 g sugar** |
| Sodium | **35 mg** |
| Caffeine | **0** |
| Sweeteners | **Aspartame + acesulfame-K** (phenylalanine warning) |
| Other | Small grapefruit juice concentrate; potassium citrate ~80 mg K |

**Verdict:** Phase-friendly free drink — use freely instead of regular soda/juice. Fits lactose rules. No meaningful macro hit.  
**Notes:** Fine with sertraline (not a grapefruit-*juice* interaction dose). If you try **Fresca Prebiotic** (~15 kcal, 6 g fiber/can): OK occasionally; don’t lean on soda for the 45g fiber target. Log 0-cal Fresca in Lose It as Fresca / diet soda.

## Desserts — shaved ice (deep dive)
Typical shop cup (~1 cup ice + syrup): ≈ **180–250 kcal · 0P · 40–55C · 0F**, almost all **sugar/HFCS**. Optional condensed milk / ice cream = +fat + lactose (skip or go light — lactase non-persistence).

| Strategy | Rule |
|----------|------|
| **Phase 1 default** | **0–1× / week**, after protein-by-5pm is hit; log in Lose It |
| **Budget** | Pull ~**40–50g** from daily **215g carbs** (swap out tortilla/rice/peri fluff that day) |
| **Order** | Small/kids size; **one syrup**; skip condensed milk / mochi / ice cream cap |
| **Better fit** | Sugar-free syrup shaved ice at home ≈ **0–20 kcal** — free like Fresca if you like the texture |
| **Not** | Nightly dessert or “I trained so I earned a large + cream” |

**Verdict:** Keep as a **liked treat**, not a staple. Texture craving → sugar-free syrup ice or Fresca + ice first.

### Homemade “shaved ice” (blender OK)
A blender **works** for the craving, but it makes **crushed / snow-cone ice**, not true fluffy Hawaiian powder (that needs a shave-ice blade). Close enough for Phase goals.

**Method**
1. Freeze water in trays; use **hard, dry ice** (not wet).
2. Pulse in a strong blender or food processor — **short pulses**, scrape sides; don’t let it melt into a smoothie. Work in small batches. Optional: chill the blender jar in the freezer 10 min.
3. Pack into a bowl/cup; drizzle syrup **lightly** (thin SF syrup sinks fast — pour in layers while packing ice).
4. Eat immediately.

**Phase syrup (prefer this nightly/anytime)**
- **Sugar-free Torani / Jordan’s / similar** (Splenda or sucralose), or SF Hawaiian shaved-ice syrup — ~**0 kcal**
- DIY: unsweetened Kool-Aid packet + granulated erythritol/Splenda + water + **tiny pinch xanthan gum** (helps cling; blend briefly)
- **Fresca pour-over:** pack blender ice, splash cold Fresca — grapefruit “soda ice” you already like

**Skip for free version:** regular syrup, condensed milk, ice cream. Those go back to the 1×/week budgeted treat.

## Dislikes (hard avoid)
- **Pickles / pickle relish** — despise; never put on plates, burgers, bowls, or “add pickles for volume”
- **Super vinegary foods** — skip pickle brine, vinegar-forward slaws, heavy vinegar hot sauces as the main flavor, vinegar-heavy BBQ (Carolina-style). Mild salsa acidity / citrus lime is OK unless you say otherwise
- **Mustard** — don’t default to it; use salsa, guac, light mayo/crema, BBQ, or cheese sparingly instead

- Mexican spots: bowls/plates with beans, rice portion controlled, fajitas, skip chips-and-salsa bottomless if it blows carbs — ask **no pickles** on anything American-Mex fusion
