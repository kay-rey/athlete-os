Yes — macros add up (2 kcal rounding).

### Fiber goal — **45 g/day** (aim 45–50)
- Comes from beans, veg, tortillas, chia, + **psyllium** Gates 2/6 (**Metamucil SF Orange**: Wk1 **½ tsp** ×2; Wk2+ **1 tsp** ×2 — see `stack/supplements.md`).
- Lose It: set fiber **45 g**. Hitting 50 is fine; don’t force fiber sodas.
- If under 30 without psyllium, you’re missing Milpa/beans — fix food, don’t just mega-dose husk.

### Sodium — don’t set a strict “under 2300” goal
You’re a sweater on hard GB; peri protocol uses **~500–750+ mg Na** with pre-mat carbs. A diet-app **max 2,300 mg** fights that.

| Day type | Practical sodium |
|----------|------------------|
| Easy / teach-only | Food sodium ~**2,000–3,500 mg** fine (rinse beans; prefer no-salt tomatoes when you can) |
| Hard GB (+ electrolytes) | **3,000–5,000 mg** total OK — include packet Na; don’t fear salt that day |
| Lose It setting | Skip a hard sodium *maximum*, or set a loose **upper watch ~5,000 mg** only to catch extreme junk days — **not** a restriction target |

Priority: **protein + calories + fiber 45**. Sodium = replace sweat on hard days, not a cutting lever.

### Ignore Lose It’s “you’ll hit goal on [date]” banner
That date (e.g. **Sep 5**) is a **toy linear projection**: fixed calories × Lose It’s own (usually lower/sedentary) TDEE until scale = goal weight. It is **not** this OS timeline.

| | Lose It banner | Athlete-OS |
|--|----------------|------------|
| Calories | Flat 2,250 forever | Phases: 2250 → 2200 → 2550 reset → 2150 → **2500** maintenance (`nutrition/phases.csv`) |
| End date | App math (often slow) | **Week 21 ≈ Apr 4, 2027** → ~172 lb target band |
| Progress rule | Calendar countdown | **Waist + adherence + GB/lifts**; ICW may stall scale Wk 1–3 |

**Use Lose It only to log food against the budget/macros.** Do not change training or panic-cut because the app says September.

## Step-by-step (iPhone)

### 1. Profile & weight
1. Open **Lose It!**
2. Profile (top right) → confirm **male**, height **5'5"**, DOB / age **32**.
3. Goals → **Weight** → current **189.7 lb** (or today’s scale).
4. Goal weight: **172 lb** (aspirational). Pace: use a **slow** pace or manual calories so the app doesn’t fight 2,250 — you’ll override calories next.

### 2. Force the calorie budget to 2,250
1. **Goals** → tap your **calorie / budget** goal.
2. Edit / customize so daily budget = **2,250** (not Lose It’s auto number).
3. Turn **off** or ignore “eat back exercise calories” if it inflates the budget — mat/lift burn is already in the plan’s TDEE model. Prefer **don’t add exercise calories back**.

### 3. Custom macros (Premium)
1. **Goals** → **Set Another Goal** → **Nutrition**.
2. Add **gram-based** goals (not %):
   - Protein **185 g**
   - Carbohydrates **215 g**
   - Fat **72 g**
   - Fiber **45 g** (optional)
3. If you see a “Nutrition strategy” / plan picker, choose **Custom** so it doesn’t overwrite with keto/high-carb presets.
4. Pin **Calories + Protein + Carbs + Fat** on the home dashboard / favorites so you see grams every day.

### 4. Logging habits (how you’ll actually use it)
1. Log **Gate 1 breakfast** and **Gate 3 lunch** yourself (you control those).
2. Log **WPI / snacks / peri carbs** when you eat them.
3. **Dinner:** wife cooks — photograph or portion, then log as best match (or custom recipe). Don’t ask her to weigh every gram unless she wants to; estimate honestly.
4. Create **Custom Foods** for staples: lactose-free WPI scoop, psyllium, chili bowl (from `nutrition/recipes/turkey_chili.md`).
5. Meals: keep Lose It’s four buckets — map them to Gates (don’t invent five custom names you’ll forget):

| Lose It meal | What goes here | Gate |
|--------------|----------------|------|
| **Breakfast** | Wake meal (eggs/oatmeal/whey) + AM LIV/creatine if with food | **Gate 1** |
| **Lunch** | Midday solid plate (chicken + beans) — post-GB lunch lands here | **Gate 3** |
| **Dinner** | Evening plate after teach / wife food / intentional top-up | **Gate 5/6** |
| **Snacks** | Gate 4 protein, peri banana/honey, Chomps, rice cakes, hungry coach grabs | **Gate 4 + peri + extras** |

Hard rule: **Dinner is not optional just because snacks filled calories.** If teach-night food was logged under Snacks, that’s fine for history — next time put the evening plate in **Dinner** so the empty Dinner row doesn’t trick you into thinking you “skipped” a Gate.

### 5. Settings that matter
1. Units: **lbs**, **grams**.
2. Reminders: lunch + evening log reminder OK; don’t obsess late-night.
3. Apple Health: OK to sync weight **out** to Health; don’t let Health workouts auto-add huge calorie bonuses.
4. Water tracking optional — not required for this OS.

### 6. Weekly
1. Sunday: confirm budget still **2,250** after any Lose It “update.”
2. Phase change (Week 7+): edit goals to the next row in `nutrition/phases.csv`.
3. Export occasionally if you want a backup; agent can also take screenshots / chat logs into `journal/meals.csv`.
